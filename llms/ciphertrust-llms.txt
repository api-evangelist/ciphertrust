# CipherTrust (Thales)

> CipherTrust Manager is Thales's centralized key- and data-security management platform and the control plane of the CipherTrust Data Security Platform (CDSP). It manages encryption key lifecycle, secrets, certificates, tokenization, and policy across on-premises, hybrid, and multi-cloud (AWS/Azure/GCP) environments, with HSM/KMIP integration and post-quantum crypto readiness. Its REST API (base path /api/v1, JWT bearer auth) is automated via an official Terraform provider, an Ansible collection, and PowerShell modules.

## APIs
- [CipherTrust Manager REST API reference](https://docs-cybersec.thalesgroup.com/bundle/latest-cdsp-cm/page/reference/index.html): REST API for keys, secrets, certificates, tokenization, users, connections, and policies. Base path /api/v1, JWT bearer authentication via POST /api/v1/auth/tokens. Served per customer deployment (appliance / private cloud / CDSPaaS).
